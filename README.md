# Java Swing Calculator

A basic calculator application developed using Java Swing.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Clear button
- Division by zero handling

## Technologies Used
- Java
- Java Swing
- AWT
- ActionListener

## How to Run
1. Clone the repository.
2. Open the project in Eclipse.
3. Run calculator.java.
